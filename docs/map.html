        What this page reads
        
  
        A CSV file with one row of column names. The names can be anything. Title rows above the names are fine. Commas, tabs or semicolons between cells all work. For an Excel file, use File, Save As, CSV UTF-8 first.
        
  
          
    
        • Days down the page or across it.
          • 
    
        • Straight time and overtime in their own columns, or on their own rows with a pay type column.
          • 
    
        • Hours as 7.75 or as 7:45.
          • 
    
        • Names in one column, like Garcia, Luis A or Luis A Garcia, or split into first and last.
          • 
    
        • Pay totals in the same file, or in a second file with one row per worker.
          • 
    
        • Rows for other jobs and for leave pay, which it leaves out and counts for you. Rows for other weeks too, when each row carries a date or a week ending date.
          • 
  
        

  
        What it does not do
        
  
        It does not know your state's codes, so you type the craft code and labor class for each classification once and save the setup. It does not write fringe benefit programs or fringe rates. It handles one contract per file. It does not read Excel workbooks, only CSV.
        
  
        It tells workers apart by ID, or by name when the file has no ID. Two workers with the same name need a worker ID column. Check how each name was split in the workers table; a name like Mary Ann Smith can split in the wrong place.
